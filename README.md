# Paper2Tree Calculator

**Paper2Tree Calculator** เป็นเว็บแอปพลิเคชันขนาดเล็ก (Mini-Project) ที่พัฒนาขึ้นเพื่อคำนวณปริมาณต้นไม้ที่ต้องปลูกทดแทนจากการใช้งานกระดาษในชีวิตประจำวัน เพื่อกระตุ้นให้เกิดความตระหนักรู้เกี่ยวกับผลกระทบต่อสิ่งแวดล้อมและรณรงค์การลดภาวะโลกร้อน (Green Tech / Eco-Friendly Utility)

---

## ✨ คุณสมบัติของระบบ (Features)
* **Real-time Calculation:** คำนวณผลลัพธ์การใช้กระดาษเทียบกับจำนวนต้นไม้ทันทีเมื่อกดปุ่ม โดยไม่ต้อง Refresh หน้าจอ (DOM Manipulation)
* **Data Validation:** ระบบดักจับข้อผิดพลาดฝั่ง Client-side เช่น กรณีปล่อยช่องอินพุตว่างเปล่า, พิมพ์สิ่งที่ไม่ใช่ตัวเลข (NaN) หรือระบุจำนวนกระดาษติดลบ 
* **Dynamic Styling:** แยกสีเน้นข้อความตัวเลขผลลัพธ์เป็นสีแดงอย่างชัดเจน เพื่อทำให้อ่านข้อมูลสำคัญได้ง่ายขึ้น (Scannability)
* **Scientific Standard:** อ้างอิงเกณฑ์การคำนวณตามมาตรฐานสิ่งแวดล้อมสากล (สัดส่วนกระดาษประมาณ 8,333 แผ่น เท่ากับต้นไม้ใหญ่ 1 ต้น)

---

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)
โปรเจกต์นี้เขียนขึ้นด้วยภาษาพื้นฐานของเว็บแอปพลิเคชัน (Vanilla Web Stack) โดยไม่พึ่งพา External Framework เพื่อฝึกฝนพื้นฐาน Logic:
* **HTML5:** โครงสร้างฟอร์มรับข้อมูลและโครงร่าง Layout
* **CSS3:** จัดแต่งหน้าตาแอปพลิเคชันให้ทันสมัย (Modern Minimal Design) เน้นโทนสีเขียวธรรมชาติ
* **Pure JavaScript (ES5/ES6):** ควบคุมตรรกะการคำนวณ, การดักจับ Event การกดปุ่ม และการจัดการ DOM
